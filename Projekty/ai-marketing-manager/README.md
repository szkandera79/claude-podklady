# AI Marketing Manager

Vlastní aplikace pro správu marketingu značek **REO Heating** a **Super Heating CZ** (a dalších):
dashboard, AI asistent v češtině, správa kampaní Meta (Facebook + Instagram) přes oficiální API,
tvorba obsahu, marketingový kalendář, reporty a kontrolované automatizace. Cíl: postupně převzít
správu kampaní od agentury.
