- `obrazky/gen_schemata.py` → SVG schémata (bez nádoby, sériově na zpátečce, paralelně 4trubkově a 3trubkově).
- `build_pdf.py <článek.md>` → tisková HTML (A4, logo z `~/Claude/REO/logo`) a PDF přes Chrome headless.
- PDF je zveřejněné v artefaktu **Manuály REO HEATING**, sekce „Schémata zapojení“ (zdroj stránky `../manualy-artefakt/`).
- Schémata jsou zjednodušená (bez pojistných armatur, expanze, filtrů) — před zveřejněním na webu nechat zkontrolovat technikem.
